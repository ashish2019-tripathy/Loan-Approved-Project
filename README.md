# Loan-Approved-Project

Project Overview -

The Loan Approval Analysis Project focuses on analyzing loan application data to understand the factors that influence loan approval and rejection decisions. The project uses Python, SQL, and Power BI to clean, process, analyze, and visualize loan applicant information.
The main objective is to identify key patterns and trends related to applicant income, credit history, loan amounts, and approval status, helping financial institutions make better data-driven lending decisions.

 Project Objectives -

Analyze loan application data to identify approval and rejection patterns.
Clean and preprocess raw datasets using Python.
Retrieve, filter, join, and analyze data using SQL.
Explore relationships between applicant profiles and loan approval status.
Build an interactive Power BI dashboard to present meaningful insights.

Tools & Technologies -

Python: Data cleaning, preprocessing, and exploratory data analysis (EDA).
Pandas: Data manipulation and analysis.
SQL: Data querying, filtering, joining, and aggregation.
Power BI: Interactive dashboards and data visualization.

Project Workflow -

Data Cleaning: Handle missing values, duplicates, and inconsistent data using Python.
Data Processing: Transform and prepare the dataset for analysis.
SQL Analysis: Perform queries to extract meaningful information and identify trends.
Exploratory Data Analysis: Analyze income, credit history, loan amounts, and approval status.
Dashboard Development: Create an interactive Power BI dashboard to visualize key performance indicators and insights.

Project Outcomes -

Identified important factors associated with loan approval decisions.
Developed data-cleaning and analytical skills.
Extracted meaningful insights using SQL.
Presented key findings through an interactive Power BI dashboard.
Demonstrated an end-to-end data analytics workflow.
